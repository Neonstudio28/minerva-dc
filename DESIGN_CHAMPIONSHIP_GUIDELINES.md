# Design Championship submission checklist

## Original creation

Minerva is an original React/Vite web application created for the Design Championship. It addresses a specific problem: people have useful knowledge but struggle to find a fair, low-pressure way to exchange it. The product lets a visitor discover an offer, compare both sides of a trade, plan a session, save it locally, and publish an offer of their own.

The project is custom-built in `src/` and is not a CMS, website builder, or unmodified template. The implementation uses React, JavaScript, CSS, Phosphor Icons and browser APIs. Publishing is optional; the local preview is the authoritative demonstration build.

## Demonstration checklist

The presenter should explain the problem, target users, exchange journey, Apple-era design decisions, three-person circle model, technical structure, local-only boundaries, learning journey, challenges, skills developed, and AI contribution. The recommended 30–60 second video path is documented shot-by-shot in [`VIDEO_DEMO_SCRIPT.md`](./VIDEO_DEMO_SCRIPT.md): Home → reciprocal match → profile → planner → My swaps → Circles → Guidelines.

## AI responsibility statement

AI supported research, visual exploration, image generation, copy drafts, implementation assistance, debugging and critique. The student contribution is the product idea, selected visual direction, information architecture, interaction decisions, asset direction, code review, testing, corrections and presentation. The student must be able to explain every demonstrated feature and must not present AI output as independent student work.

## Category and judging alignment

The project is suitable for either Middle or Senior judging; participant age determines the submitted category. The rubric is addressed in [`JUDGES.md`](./JUDGES.md): design thinking through reciprocal exchange and circles, UX through desktop navigation and readable states, technical quality through tested React flows, innovation through directed circles, and presentation through the documentation pack.
