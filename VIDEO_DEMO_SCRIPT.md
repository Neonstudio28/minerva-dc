## Recording notes

- Keep the final video between **45 and 55 seconds**. Do not show mobile navigation; this project uses one desktop navigation model.
- Use readable browser zoom and avoid fast cursor movement. Let each headline remain on screen long enough to read.
- If recording voiceover is difficult, use the voiceover text as large captions and keep the same shot timings.
- The strongest ending is the Guidelines panel because it visibly supports the originality and AI disclosure requirements.
